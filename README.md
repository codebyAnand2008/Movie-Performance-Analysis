🎬 **Movie Performance Analysis Dashboard | Excel Project**

I’m excited to share my **Movie Performance Analysis Dashboard**, created using **Microsoft Excel** to analyze movie data and turn raw information into meaningful insights! 📊

🔍 **Project Overview:**
The dashboard explores movie runtime, popularity, budget, revenue, and year-wise performance using interactive charts and slicers.

📌 **Key KPIs & Insights:**
✅ **Movie Runtime:** Identified movies with the highest runtimes.
✅ **Movie Popularity:** Compared popularity scores, with *Minions* leading among the movies displayed.
✅ **Budget vs. Revenue:** Compared movie budgets and revenues to understand financial performance.
✅ **Year-wise Runtime:** Analyzed total runtime across different release years.
✅ **Interactive Filters:** Used slicers to filter data by release year and original language.

🛠️ **Tools & Skills Used:**

* **Microsoft Excel** – Data cleaning, analysis, and dashboard creation
* **PivotTables & PivotCharts** – Summarizing data and visualizing trends
* **Excel Slicers** – Interactive data filtering
* **Data Visualization** – Presenting insights clearly


💡 **Business Impact:**
This project demonstrates how Excel dashboards can help users explore movie trends, compare financial performance, and make data-driven decisions in the entertainment industry.
